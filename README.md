
# Logistics Root-Cause Analysis

## Project Note
This is an educational project using simulated data.
It is not actual company operational data.

## Dataset
- 60,000 cleaned shipments
- 12 simulated hubs
- Multiple routes and vehicles
- Two quarters: Q1 and Q2 2026

## Main Metric
On-Time Delivery Rate = on-time shipments / total shipments * 100

## Results
- Q1 On-Time Rate: 26.64%
- Q2 On-Time Rate: 26.68%
- Change: -0.04 percentage points

## Files
- cleaned_shipments.csv
- cleaned_scan_events.csv
- hypothesis_log.csv
- driver_tree.png
- weekly_early_warning.csv
- root_cause_memo.docx

## Methods
Data cleaning, segment analysis, t-tests, chi-square tests,
logistic regression and weekly monitoring.

## Limitation
Statistical associations in simulated data do not establish
real-world causation. Actual company data is required for
business conclusions.
